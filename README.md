Village Simulator is a personal project where I set out to recreate the atmosphere and daily activities of rural village life inside a 3D Unity environment. 
The game allows players to plant and harvest crops, interact with NPCs, explore the village freely, and save their progress as they play. 
I built Village Simulator as my bachelor’s thesis project, aiming to recreate rural life through interactive farming mechanics, autonomous NPCs, and a dynamic 3D world.

Features:
    Players can plant seeds, water the soil, and harvest crops once they’re fully grown. Each plant type has its own growth stages defined through ScriptableObjects.
    I built a simple inventory system where players can store harvested crops or sell them for in‑game currency. Items are defined in a modular way using ScriptableObjects.
    The village includes NPCs that move around on their own using Unity’s NavMesh and waypoint navigation. Their purpose is to make the world feel more alive and dynamic.
    A dynamic lighting system simulates the passage of time, creating smooth transitions between day and night.
    Player progress (inventory, crop states, player position, time of day, etc.) can be saved and loaded. I used JSON serialization for storing game data.


 Tehnologies used:
   Unity
   C#
   Blender (for some 3D Models)
